# ゲームルール

遊戯王 OCG のルールそのものを記述する。  
**このアプリの実装が無くても成立する、普遍的な知識**だけを置く。  
なお、記述するルールは本アプリのスコープ（先攻 1 ターン目・1 人用）に必要な範囲に絞る。

このディレクトリは他のどのドキュメントにも依存しない（[../README.md](../README.md) の「ドキュメント間の依存ルール」を参照）。  
実装への対応（実装識別子・パスの転記、実装状況、等）や「どう作るか」は [design/](../design/) 側に置く。

ここで概念に与える名称（和名・英名）は、本プロジェクトのユビキタス言語の正式定義とする。  
公式用語ではなく、本プロジェクトとして命名した造語も含む。
