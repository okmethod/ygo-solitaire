# 特殊勝利条件

カード固有の効果・条件によって、ライフポイントの増減とは無関係に即座に勝敗が決まる勝ち方を「特殊勝利」と呼ぶ。

> ライフポイント 0・デッキアウトなど一般的な勝敗判定は [overview.md の Victory Decision](./overview.md) を参照。

特殊勝利条件は、ゲーム状態が更新されるたびに自動で判定される。

---

## 封印されしエクゾディア

**条件**: 以下の 5 枚すべてが**手札**に揃う

- `封印されしエクゾディア` (本体)
- `封印されし者の右腕`
- `封印されし者の左腕`
- `封印されし者の右足`
- `封印されし者の左足`
