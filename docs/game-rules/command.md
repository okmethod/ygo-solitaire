# ゲーム操作コマンド

プレイヤーが取れる行動（召喚・セット・発動など）。各行動には実行条件があり、満たす場合のみ行える。

---

## 共通パターン

### 実行可能性チェック

- **ゲーム終了状態**: ゲームが終了している場合、すべての操作は実行不可
- **タイミング制約**: 特定のタイミングでのみ実行可能等の条件を確認する
- **リソース制約**: 必要なリソース（カード、ゾーンの空き等）が存在することを確認する
- **ゲームルール**: 遊戯王のルールに基づく条件（例: 召喚権、ターン 1 制限等）を確認する

### 実行結果

- **成功**: ゲーム状態が更新され、次の操作が可能になる
- **失敗**: ゲーム状態は変更されず、実行されない
- **効果処理**: カード効果が発動し、効果処理が行われる

## コマンド一覧

**凡例**: ○ スコープ内 / × スコープ外（先攻 1 ターン目では実行不可のため）

| カテゴリ   | コマンド名               | スコープ | 説明                           |
| ---------- | ------------------------ | -------- | ------------------------------ |
| ゲーム進行 | Advance Phase            | ○        | 次のフェイズに遷移する         |
| モンスター | Summon Monster           | ○        | モンスターを通常召喚する       |
| モンスター | Set Monster              | ○        | モンスターをセットする         |
| モンスター | Synchro Summon Monster   | ○        | モンスターをシンクロ召喚する   |
| モンスター | Flip Summon Monster      | ×        | モンスターを反転召喚する       |
| モンスター | Change Battle Position   | ×        | モンスターの表示形式を変更する |
| 魔法・罠   | Set Spell/Trap           | ○        | 魔法・罠カードをセットする     |
| 魔法・罠   | Activate Spell           | ○        | 魔法カードを発動する           |
| 魔法・罠   | Activate Trap            | ×        | 罠カードを発動する             |
| 効果       | Activate Ignition Effect | ○        | 起動効果を発動する             |
| バトル     | Attack                   | ×        | 攻撃する                       |
